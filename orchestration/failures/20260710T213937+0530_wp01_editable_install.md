# Failure report

## Task

T-WP01 repository foundation editable-install acceptance test.

## Failed command

```text
python3 -m pip install --no-deps --no-build-isolation -e .
```

Exit code: `1`.

## Error

The editable wheel built successfully, but pip could not install it:

```text
ERROR: Could not install packages due to an OSError: [Errno 30] Read-only file system: '/home/akki/.local/lib/python3.13'
```

Pip defaulted to user installation because the environment site-packages directory is not writable.

## Files changed before failure

The T-WP01 foundation files and passing test changes were already present. The test run also generated Python bytecode under `src/semifab_poc/__pycache__/`. No deliberate source changes occurred after the failure.

The build produced an ephemeral editable wheel under `/tmp`; no repository wheel was written.

## Read-only diagnosis

- Package metadata preparation and editable wheel construction both succeeded.
- The failure occurred only during installation to `/home/akki/.local/lib/python3.13`.
- `/home/akki/.local` exists, but `/home/akki/.local/lib/python3.13` does not exist and the user site is not writable in this managed environment.
- The repository itself is writable and the package imports under the configured `src` path; pytest passed all 6 tests.
- No network access, credentials, public dataset, optional dependency, scientific model, or external service was involved.

## Likely causes

The managed Python environment prevents writes to both system site-packages and the default user site. An editable install therefore needs an explicitly writable target, such as a project-local virtual environment.

## Recovery options

1. Create a project-local virtual environment inside the repository and run the editable install there with `--no-deps` (or with dependencies only if separately approved), then rerun the acceptance suite.
2. Use a writable external environment or user-approved installation target and rerun the install check.
3. Treat the successful editable-wheel build plus `PYTHONPATH=src` import/test checks as the current packaging evidence and leave the editable-install acceptance item unresolved.

## Recommended option

Option 1. A project-local virtual environment is reversible, within the repository scope, and tests the intended editable installation without writing to protected global locations.
