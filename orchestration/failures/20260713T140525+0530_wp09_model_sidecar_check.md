# Failure report

## Task

Verify the six WP09 serialized-model checksum sidecars immediately before Git
staging.

## Failed command

```text
sha256sum -c hybrid.pkl.sha256 linear.pkl.sha256 mean.pkl.sha256 \
  physics.pkl.sha256 ridge.pkl.sha256 tree.pkl.sha256
```

The command ran from `reports/virtual_metrology/models/`.

## Error

GNU `sha256sum -c` returned exit code 1 and reported that every sidecar lacked a
properly formatted checksum line.

## Files changed before failure

None. Checksum inspection is read-only, and Git staging had not begun.

## Read-only diagnosis

The project model serializer intentionally writes each `.sha256` sidecar as one
bare 64-character digest. GNU check mode instead requires a digest followed by
a filename. Direct comparison confirms every bare sidecar digest exactly equals
the corresponding model's freshly computed SHA-256:

| Model | Matching SHA-256 |
|---|---|
| hybrid | `7107eb17191e860c2c0d0ded66e051ffd0c80b37128c390b8d78877ed2d19f84` |
| linear | `0ada8d112b97777aba11b4b623293ef5449d4b9169b407717b11428a3439c265` |
| mean | `aac2e4c439a735e65b4378966607dc5afe339ab6f652874ca0b55fb90b6d2a01` |
| physics | `831c8d9a4f41befb19d5cee16e760bee5dab74b6bfbdb0b2a8f7a68b1da7ac89` |
| ridge | `f49c6671fb58882b68bab5642018e7e31c5d911b0eb7f1adb3540b8b7a2a99e8` |
| tree | `140f395f4735f22edce20df444e36ac96a6ffde9c8006e15707f08dabe404184` |

This is a validator-format mismatch, not artifact corruption.

## Likely causes

1. The audit assumed GNU checksum-file syntax without first inspecting the
   project's bare-digest sidecar contract.
2. The serializer's loader verifies bare digests internally, whereas
   `sha256sum -c` does not support that format.

## Recovery options

1. Recommended: accept the direct six-of-six digest comparison, preserve the
   frozen sidecars unchanged, and continue with the planned Git checkpoint.
2. Change the sidecar format and serializer/loader contract, then regenerate
   every model and affected hash record. This would alter frozen WP09 artifacts
   and is not justified by the audit-command mismatch.
3. Exclude serialized models from the checkpoint and weaken reproducibility.

## Recommended option

Option 1. All model bytes match their recorded digests; no artifact repair or
contract change is needed.

## User decision required

Authorize option 1 before Git staging or any further mutation.
